# 🐍 Snake Game

A modern and interactive browser-based Snake Game built with **HTML, CSS, and JavaScript**.

This project takes the classic Snake experience and combines it with a modern interface, multiple themes, power-ups, missions, achievements, statistics, a virtual shop, and sound effects.

🚀 **Play the game:**

## ✨ Features

### 🐍 Classic Snake Gameplay

* Smooth snake movement
* Keyboard controls
* WASD support
* Arrow key support
* Mobile touch controls
* Swipe controls
* Pause and restart functionality
* Increasing difficulty

### ⚡ Power-Ups

The game includes several power-ups that can change the gameplay:

* ⚡ **Speed** — increases the snake's movement speed
* ✨ **2X Points** — doubles points earned
* 🛡️ **Shield** — protects the snake
* 🧲 **Magnet** — attracts nearby food
* ❄️ **Slow** — temporarily slows the game
* 👻 **Ghost** — provides special movement abilities
* ❤️ **Life** — gives an additional life

### 🎨 Themes

Choose between different visual themes:

* 🌌 Neon
* 🌙 Dark
* ☀️ Light
* 🌲 Forest
* 🔥 Lava
* ❄️ Ice

The selected theme is saved for future sessions.

### 🏆 Achievements

Players can unlock achievements by completing different challenges.

The game includes:

* Achievement tracking
* Unlock notifications
* Achievement progress
* Achievement modal
* Persistent achievement data

### 🎯 Daily Missions

Complete daily challenges to earn rewards.

The mission system includes:

* Daily objectives
* Progress tracking
* Coin rewards
* Automatic daily reset
* Countdown until the next reset

### 🛍️ Shop

Use earned coins to customize your gameplay experience.

The shop includes:

* 🐍 Snake skins
* ✨ Visual effects
* 🪙 Virtual currency
* 🔓 Unlockable customization options

### 📊 Statistics

Track your performance with detailed statistics, including your progress and gameplay history.

## 🎵 Sound System

The game includes a dynamic sound system designed to make gameplay more immersive.

Sound effects can be triggered by events such as:

## 📈 Game System

The game contains a progression system designed to make each run more challenging.

As the player progresses:

**Score increases → Level increases → Difficulty increases**

This creates a progressively faster gameplay experience.

---

## 💾 Data Persistence

Player progress is stored locally in the browser using **LocalStorage**.

This allows the game to remember information such as:

* High score
* Coins
* Selected theme
* Purchased skins
* Unlocked effects
* Achievements
* Missions
* Statistics

No external database is required.
